
# 🏨 Hotel Booking Website

A full-stack Hotel Booking Web Application built using React.js,
Node.js, Express.js, and MongoDB.

The application allows users to explore hotels and rooms, check room
availability, and make reservations through a user-friendly interface.
It also includes authentication, booking management, and a dashboard
for hotel-related information.

## 🚀 Features

- Browse available hotels and rooms.
- View room details, facilities, and pricing.
- Check room availability based on check-in and check-out dates.
- Create hotel room reservations.
- Authenticate users using Clerk.
- Protect booking-related API endpoints.
- Manage user bookings.
- Calculate booking prices based on room rates and stay duration.
- Provide a hotel dashboard with booking statistics and revenue data.
